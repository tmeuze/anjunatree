Privacy Policy

Last updated 20 August 2026

Short version: AnjunaTree has no accounts, no cookies, and no server to collect anything on. Everything it stores lives only in your own browser. The only outside services your browser talks to are Apple's iTunes Search API, and Spotify if you choose to connect it.

What's stored in your browser

AnjunaTree is a static site with no backend — nothing below is ever sent to a server, because there isn't one. Clearing your browser's site data for anjunatree.com removes all of it.

  • Preferences — theme, text size, and accessibility settings.
  • App version last seen — so the "what's new" changelog only shows updates since your last visit.
  • A Spotify session, if you connect one — an access/refresh token issued directly by Spotify to your browser via PKCE OAuth. AnjunaTree's own code never sees your Spotify password; sign-in happens entirely on Spotify's site. "Disconnect Spotify" in Settings clears this.
  • Your saved-releases cache, if you turn that setting on — a locally cached list of which releases you've saved on Spotify, so the map doesn't have to re-check on every visit.

Third-party services

Your browser talks directly to these — AnjunaTree has no server in between, so it never sees the requests or responses:

  • Apple's iTunes Search API — every 30-second preview clip and piece of artwork is fetched live from Apple by your browser. Governed by Apple's own privacy policy.
  • Spotify — only if you choose to connect an account, for full-track playback, your saved-releases list, and playlist export. Governed by Spotify's Privacy Policy.
  • GitHub Pages — hosts and serves the site itself. Governed by GitHub's Privacy Statement.

Analytics

No analytics are enabled by default. Some deployments of this open-source project may enable self-hosted, cookie-free Umami analytics, configured only by whoever runs that deployment. Umami does not use cookies and does not collect personally identifying information, and respects Do Not Track when enabled here. The project's source code (linked below) shows exactly how and when this can turn on.

What isn't collected

No accounts, no email addresses, no IP-address logging by AnjunaTree itself, no cross-site tracking, no advertising, no sale of data — there is no server for AnjunaTree to collect or sell anything from.

Changes

If AnjunaTree's data handling ever changes, this page will be updated and the change noted in the project's changelog.

Questions

AnjunaTree is maintained by volunteers on GitHub — open an issue with anything unclear.
